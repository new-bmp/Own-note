# Own

一款以工作效率为重点的无限画布笔记应用。文字、便签、照片、表格、代码、数据分析和任意文件都可以自由放置、移动、调整大小，并用连线建立关系。同一项目可以在自由画布、任务清单、资料库和 Agent 构想之间切换。

## 桌面客户端

Windows 版本使用原生窗口和 WebView2。运行 **release/Own-Setup.exe** 安装后，可从开始菜单或桌面快捷方式打开；也可解压 `release/Own-win-x64.zip` 使用便携版。应用自动启动随包的 Node.js 保存与 MCP 服务，不需要打开浏览器或安装 Node.js/.NET。

源码运行：`npm run desktop`；热更新：`npm run desktop:dev`；便携包：`npm run desktop:package`；安装程序：`npm run desktop:installer`。构建机需 .NET 10 SDK。客户端笔记保存在 `%LOCALAPPDATA%\Own\workspace`，安装、升级和卸载均保留笔记。[客户端使用与构建说明](docs/desktop.md)。

## 网页开发与服务调试

需要 Node.js 22.18+，推荐 Node.js 24 LTS。

```sh
npm install
npm run dev
```

打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。开发模式由 Node.js 提供接口和 Vite 热更新，只需启动一个进程。

正式运行：

```sh
npm run build
npm start
```

`npm run preview` 同样使用 Node.js 提供正式构建及保存接口。默认仅监听本机 `127.0.0.1:5173`；可通过 `PORT` 调整端口，通过 `FIELDNOTES_DATA_DIR` 指定数据目录。

## 使用

- 左侧工具栏选择文字、便签、表格或待办，再点击画布放置；右上角「添加内容」可直接在视野中央创建。
- 拖动卡片自由摆放；选中后拖动右下角调整大小；双击文字、表格单元格直接编辑。
- 任意类型的文件、整个文件夹可从文件管理器直接拖入，或点击「添加文件 / 添加文件夹」。导入会将原文件复制到笔记中，单文件上限 100 MB；显示进度与失败原因，成功文件不会因其他文件失败而丢失。
- 文件夹卡片可逐层浏览、搜索文件、预览内容，将其中的文件单独放到画布，或导出 ZIP。直接拖入会保留空目录；系统的文件夹选择器只返回含文件的目录。每次导入最多 10000 个目录条目、64 层子目录。
- 图片、PDF、音视频、文本、代码、Markdown、公式和 Mermaid 文件可预览。DOCX / XLSX / PPTX 提供文字与表格内容预览；原始排版、图片、图表及其他格式可另存为，客户端可用系统应用打开常见文档。文本预览上限 1 MB，原文件完整保留；文件夹 ZIP 导出上限 250 MB，较大资料可使用完整备份。
- 支持粘贴文字、图片、网页地址，以及从电子表格复制的制表符表格。
- 选中卡片后，从四侧圆点拖到另一张卡片即可连接；也可用 C 连线工具依次点击两张卡片。点击线条可编辑关系文字、曲线 / 直线 / 折线、单向 / 双向 / 无箭头、虚线、颜色与方向，支持删除和撤销。
- 按住空格拖动画布，Ctrl / Command + 滚轮缩放；手机可拖动空白处漫游，双指缩放。
- 支持多个画布、收藏、最近打开、回收站恢复、跨画布搜索和撤销重做。
- 「任务清单」汇总当前项目所有待办，支持筛选、搜索、优先级、截止日期与来源定位，修改同步回画布。
- 「资料库」集中查看文档、图片和参考链接，支持分类筛选、搜索、预览与来源定位。
- 「快速记录」支持笔记和任务；新建画布时可选择空白、项目计划或会议记录模板。
- 「整理画布」一键整理卡片位置，支持撤销；「网格吸附」可选开启；F 切换桌面专注模式。
- 右上角调色图标打开「外观与配色」：可选主题色和画布背景预设，也可用颜色选择器或 HEX 色值自定义；修改实时预览，保存后生效，取消可还原。
- 选中任意卡片，点击浮动工具栏的调色图标，可设置独立背景颜色或恢复默认；深色卡片会自动使用浅色文字。配色修改支持撤销。
- 侧栏、任务信息、文件详情和编辑提示使用更清晰的文字颜色。自定义配色时，主题按钮、画布提示和卡片正文会自动调整，保持至少 4.5:1 的对比度。

## Agent、公式与图

左侧「连接 Agent」提供 MCP 的 HTTP / stdio / Codex 配置和可复制的完整整理要求。agent 可提交完整 Markdown 正文及摘要、决策、行动项和图，服务自动拆卡、摘要置顶并按两列排布。保存结果返回实际接收数量与正文一致性核对；`own_read_conversation` 可读回整份记录，避免只存摘要后误报完成。共 16 个工具，写入可重试，已有内容更新有版本保护。

「添加内容」支持 Markdown、LaTeX 公式、Mermaid 图及柱状 / 折线 / 饼图。工具栏的「公式输入器」可直接编辑分数、根号、上下标、求和、积分和矩阵，提供数学键盘、结构空位跳转、常用示例与 LaTeX 源码切换；字体随包携带。

「流程图制作器」通过中文节点名称、形状、起终点和关系文字生成 Mermaid，可设置阅读方向、虚线、箭头，实时预览。支持流程、判断分支模板；时序图与思维导图提供源码模板。已有高级 Mermaid 源码保持原样，不会自动转成表单或覆盖；使用模板替换需要点击明确的替换按钮。公式和图编辑器支持 Ctrl / Command + Enter 保存。

点击「阅读会话」可按目录通读正文、任务及图，「阅读全文」展开独立笔记。图表可核对原始数据并导出 SVG。页面空闲时自动接收 agent 更新。连接方式、工具参数和同步规则见 [MCP 使用说明](docs/mcp.md)。

## 代码、媒体、3D 与数据分析

- 「添加内容 → 多语言代码笔记」提供独立代码单元、语法高亮、标准输入、预期输出比较、实时 stdout / stderr 和停止。内置 JavaScript、TypeScript、SQL、JSON 与隔离 HTML 预览；Python、C、C++、Java、Go、Rust 使用本机运行环境。每单元独立进程，执行结果随笔记保存。
- 音视频预览增加倍速、音量、跳转、循环、A–B 区间与时间点导出。随包 FFmpeg 可将兼容的原始音视频转换为 MP3 / MP4，无需另外安装转换器；转换输出可另存，原文件保留。可播放范围受实际编码限制，受保护、损坏或缺少解码器的文件会显示错误。
- 3D 查看器支持 GLB / glTF、OBJ + MTL、STL、PLY、FBX、3MF，可旋转、缩放、平移、线框、网格、自动旋转和导出视图。有关联缓冲区或贴图时，导入完整文件夹；外部联网资源和需要额外解码器的压缩模型暂不加载。
- 数据分析笔记支持 CSV / TSV / JSON / XLSX，提供筛选、排序、空值与数值统计、分组聚合、图表及筛选结果导出；分析配置和原始数据一起保存。上限 2 MB 文本、50000 行、200 列，超限会报错，不会把预览截断结果当作完整数据。
- 「Agent 构想」展示公开方案、待实现、执行中、已实现、阻塞、暂停和真实心跳。修改未实现笔记会撤销旧执行凭证，Agent 下一次报告后须重新领取。连接客户端需要主动使用 `own_publish_plan`、`own_agent_next`、`own_agent_report` 协议；仅安装 MCP 配置不会自动读取其内部 todo 或驱动它继续执行。

详细操作、格式与运行限制见 [工作台使用说明](docs/workbench.md)。

## 保存与备份

无需账号。Node.js 自动把画布、任务、坐标、连接和全局配色保存在 `data/notebook.json`，附件保存在 `data/assets/`。浏览器仍保留笔记和附件缓存。刷新或重启服务后恢复内容；缩放和漫游位置在打开画布时重新调整。

首次启动且服务端数据为空时，会迁移当前浏览器中已有的笔记与附件。后续以服务端数据为准，同一本地服务在不同浏览器中打开也能读取同一份工作空间。保存时可合并独立笔记修改和 Agent 心跳；同一字段存在不同修改时拒绝覆盖，未保存记录可保留为恢复副本。

「导出 → 完整备份」生成包含所有画布、配色和导入附件的 `.own` 文件，可通过「导入画布备份」恢复。已有 `.fieldnotes` 备份仍可导入。导入会新增画布，不覆盖现有记录，并恢复备份中的全局配色。也可以将当前画布的文字、待办和表格导出为 Markdown。

`data/` 不纳入 Git；也可在停止服务后直接备份整个数据目录。清除浏览器缓存不会删除 Node.js 已保存的文件。本版本是本机个人工作空间，尚未提供云同步、多人实时协作、自由手绘和离线应用缓存。单个附件上限 100 MB。

工作效率版首次打开已有笔记时，会新增产品项目示例，并保留现有画布与附件。此迁移只执行一次。

## 技术与验证

Node.js 原生 HTTP 与文件接口，前端使用 React 19、TypeScript、Vite 和 Lucide。附件只发送到当前本机 Node.js 服务。

运行 `npm test` 检查数据迁移、布局整理、模板、Node.js 持久保存与重启恢复、附件读写、并发保存冲突、无效内容保护和正式静态服务。

已通过生产构建，以及浏览器内的编辑与刷新恢复、拖动与调整大小、待办、表格、复制删除与撤销重做、搜索定位、图片与文件导入、图片预览、附件备份导出及重新导入的操作验证。

工作示例的流程图为本项目本地 SVG。旧版示例摄影来自 [Unsplash](https://unsplash.com/photos/3b5ec3a7fe05)，字体使用 DM Sans / Noto Sans SC，并提供系统字体回退。
