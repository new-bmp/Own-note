# Own 工作台

版本 1.2 增加代码笔记、媒体控制器、3D 查看器、数据分析及 Next to do for agent。它们都在 Windows WebView2 客户端中使用；资料仍保存到本机工作空间。

## 多语言代码笔记

点击「添加内容 → 多语言代码笔记」，双击卡片或点击「打开工作台」进入。每本笔记最多 40 个独立单元，可选语言、载入示例、调整顺序、填写 stdin 与预期 stdout。点击运行或按 Shift + Enter，输出会实时出现；停止会结束进程及其子进程。完成后点击「保存笔记」，将源码、输入、输出、错误、时间与执行次数保存。修改源码、语言或输入后，界面会提示旧输出需要重新运行。

| 语言 | 执行方式 |
| --- | --- |
| JavaScript | 随包 Node.js，支持 ES module / 顶层 await |
| TypeScript | Node.js 去除类型语法后执行；不支持需要转换的 enum 等语法 |
| SQL | SQLite 临时内存数据库，支持多条语句、查询结果与触发器 |
| HTML | 点击后在隔离 iframe 运行内联脚本与样式，禁止联网 |
| JSON | 解析校验与格式化 |
| Python | PATH 中的 `python`，隔离模式 `-I` |
| C / C++ | PATH 中的 `gcc` / `g++` 编译后运行 |
| Java / Go / Rust | PATH 中的 `java` / `go` / `rustc` |
| CSS / C# / Shell / Markdown | 编辑与保存示例 |

每个单元独立临时进程，变量、包和数据库不在单元间共享；当前不是 Jupyter kernel。缺少运行环境时显示安装提示。默认运行 15 秒，最多 30 秒，编译最多 60 秒；整个应用最多并行 3 个代码或转换任务。合计输出上限 256 KB，超限停止并标记，不把截断输出当作完整运行。

代码是在本机执行，具有当前用户权限；只主动运行理解且信任的代码。MCP 的 `own_add_code` 只保存，不自动执行。HTML 的隔离预览不会获得 Own 工作空间或本机文件访问权限。

## 媒体控制器

拖入音视频后点击查看。提供播放/暂停、前后 10 秒、进度、0.25–3 倍速、音量、静音和循环。先设置 A，再跳到较后位置设置 B，可循环练习一段内容；时间点可以跳转或导出文本。

常见扩展名均会进入播放器，包括 MP3、WAV、FLAC、AAC、M4A、Opus、AIFF、WMA、MP4、WebM、MOV、MKV、AVI、WMV、FLV、MPEG、MTS、3GP、VOB 等。能否直接播放取决于 WebView2 的编码支持。点击「转换为兼容格式」使用随包 FFmpeg 转为 MP3，或 H.264 / AAC MP4。转换记录显示实时进度、错误与停止；最长 5 分钟，输出小于 500 MB。转换是临时播放副本，持久保存请点击「保存转换结果」，或把保存的文件重新拖入笔记。

损坏文件、DRM、特殊编码以及 MIDI 等需要合成器的格式无法保证转换。任意格式仍可作为原始附件保存和另存。转换器随包提供 GPL 许可及上游构建信息，路径为 `app/node_modules/ffmpeg-static/ffmpeg.exe.LICENSE` 和 `ffmpeg.exe.README`。

## 3D 查看器

支持 GLB / glTF、OBJ / MTL、STL、PLY、FBX、3MF。拖动旋转，滚轮缩放，右键平移；可重置视角、切换线框/网格、自动旋转、保存 PNG。可播放模型自带动画，并显示顶点、三角面和动画数量。

将包含模型、材质、二进制缓冲区和贴图的文件夹整体拖入，通过文件夹浏览器打开模型。把其中的模型单独放到画布时仍保留关联附件。单模型 100 MB，关联资源最多 200 个，总计 150 MB。联网资源、Draco / Meshopt / KTX 等需要附加解码器的资源暂不支持，缺失资源会显示具体名称。

## 数据分析

粘贴 CSV / TSV / JSON，或导入不超过 2 MB 的 CSV、TSV、JSON、XLSX。第一行是表头；JSON 支持对象数组或二维数组。Excel 读取第一个有数据的工作表，使用已缓存的单元格结果；需要其他工作表时分别导出 CSV。未计算的公式或超限数据会报错。XLSX 分析不会沿用 Office 预览的 1000 行截断。

可筛选、点击列头排序、按 100 行翻页；统计有效数值、空值、不同值、总和、平均、中位数、范围和样本标准差。分组支持求和、平均和计数，并生成柱状、折线或饼图，最多展示数值最高的 60 组。点击「把图表放到画布」保存独立图表，点击「导出筛选结果」保存 CSV。原始数据和分析配置会随笔记保存；CSV 导出对公式文本作转义。

## Next to do for agent

先在「连接 Agent」配置 MCP，并复制「构想协作要求」。在「Agent 构想」创建任务，或让 Agent 发布公开方案与任务。公开内容包括目标、依据、执行要求、验收标准、依赖、进展、产物和验证证据。

客户端需按以下协议执行：

1. `own_publish_plan` 发布方案与可编辑任务，使用稳定 `requestId`，重试不会覆盖用户修改。
2. `own_agent_next` 领取依赖已完成的任务，获得笔记当前 `revision` 和 `leaseToken`。
3. 执行前、关键动作后和至少每 30 秒调用 `own_agent_report`，提交真实进展。凭证有效 120 秒，近期 75 秒内有心跳显示在线。
4. 用户修改要求、改变依赖、暂停或删除任务后，旧报告返回 `accepted: false, needsReplan: true`。停止旧方案，重新领取最新任务。恢复为待实现的前置任务也会使后续执行凭证失效。
5. 实际完成并验证后，提交 `status: done` 和 `evidence`。完成任务锁定要求；用户可以重新打开并保留原结果。

未收到近期心跳会显示离线；已过期的任务在下一次领取/报告时回到待实现。暂停任务不会被领取，循环依赖不会保存。恢复备份时会撤销旧凭证并清空在线记录。

Own 监控遵守此协议的客户端，不能读取未上报的内部 todo，也不会自动唤醒或启动外部 Agent。笔记修改在下一次检查时影响后续执行，已发生的外部动作需要 Agent 另行处理。用户修改不会扩大 Agent 原有授权范围。
