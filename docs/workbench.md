# Own 工作台

版本 1.6 增加一体化可编程应用、真实单步调试、可编辑数据表、表格式图表制作、独立 Agent 模式和随包工具链。它们都在 Windows WebView2 客户端中使用；资料仍保存到本机工作空间。

## 多语言代码笔记

点击「添加内容 → 多语言代码笔记」，双击卡片或点击「打开工作台」进入。每本笔记最多 40 个独立单元，可选语言、载入示例、调整顺序、填写 stdin 与预期 stdout。点击运行或按 Shift + Enter，输出会实时出现；停止会结束进程及其子进程。完成后点击「保存笔记」，将源码、输入、输出、错误、时间与执行次数保存。修改源码、语言或输入后，界面会提示旧输出需要重新运行。

| 语言 | 执行方式 |
| --- | --- |
| JavaScript | 随包 Node.js，支持 ES module / 顶层 await |
| TypeScript | Node.js 去除类型语法后执行；不支持需要转换的 enum 等语法 |
| SQL | SQLite 临时内存数据库，支持多条语句、查询结果与触发器 |
| HTML | 点击后在隔离 iframe 运行内联脚本与样式，禁止联网 |
| JSON | 解析校验与格式化 |
| Python | 默认安装的官方 Python，隔离模式 `-I` |
| C / C++ | 默认安装的 GCC / G++ 编译后运行 |
| Java / Go / Rust | 安装程序中可选择的运行组件 |
| CSS / C# / Shell / Markdown | 编辑与保存示例 |

每个单元独立临时进程，变量、包和数据库不在单元间共享；当前不是 Jupyter kernel。优先使用随包组件，缺少时检测本机环境并提示补装。默认运行 15 秒，最多 30 秒；编译最多 60 秒，Go 首次编译最多 90 秒。整个应用最多并行 3 个代码或转换任务。合计输出上限 256 KB，超限停止并标记，不把截断输出当作完整运行。

点击「单步调试」进入逐行工作台，高亮行将在下一步执行。提供下一步、进入函数、跳出函数、继续到断点、暂停及停止。暂停时点击行号设置断点；变量面板显示当前作用域，支持筛选变量名和观察 `total`、`items[0]` 等表达式。JavaScript / TypeScript 和 C / C++ 可切换调用栈帧；Python 显示当前帧与调用栈。观察表达式用于读取，不能调用函数或修改值。调试结束后点击返回编辑，再保存运行结果。最多同时调试 2 个单元；连续运行限 30 秒，暂停会话保留 30 分钟。

## 一体化可编程应用

可编程块的「应用界面 · Flask」区域可以选择一个 Python 单元作为入口。点击「插入 Flask 示例」即可得到一个带 HTML 页面和 `/echo` JSON 接口的应用；点击「启动应用」后，Own 在本机回环地址启动进程，并把界面嵌入当前可编程块。应用的代码、动画、设备驱动、请求输入、响应正文和运行日志都属于同一个块，保存工作台后一起保存配置。

请求面板支持 GET、POST、PUT、PATCH 和 DELETE，可填写路径与 JSON / 文本正文，直接查看状态码、响应头和完整正文。应用内的表单和脚本也可以请求相对路径，Own 会通过安全代理转发到该应用；应用只监听 `127.0.0.1`，关闭工作台时会释放进程和端口。应用入口使用 `OWN_APP_PORT`，不要硬编码其它端口。

Own 优先使用真实 Flask。随包嵌入式 Python 没有第三方包时，会启用离线兼容层，支持常用的 `Flask`、`@app.route` / `@app.get` / `@app.post`、`request.args`、`request.form`、`request.get_json`、`jsonify`、`render_template_string`、`redirect` 和 HTML 响应；需要 Flask 扩展或完整 Jinja 能力时，在自己的 Python 环境中安装真实 Flask 后再运行。应用由用户显式启动，MCP 也不会在保存时自动执行。

可编程块顶部会显示「准备入口 → 启动应用 → 预览与验证 → 扩展功能」四步提示。代码单元是主要编辑区，动画和设备驱动默认收起，需要时再展开，避免把所有控制项同时堆在一起。

交互网页卡片进入画布后，工具栏提供 50%–200% 的网页内部缩放、百分比重置和独立滚动视口；缩放只影响当前网页显示，不会改变画布卡片尺寸。

安装组件、来源及许可见 [随包工具说明](toolchains.md)。

代码是在本机执行，具有当前用户权限；只主动运行理解且信任的代码。MCP 的 `own_add_code` 只保存，不自动执行。HTML 的隔离预览不会获得 Own 工作空间或本机文件访问权限。

## 媒体控制器

拖入音视频后点击查看。提供播放/暂停、前后 10 秒、进度、0.25–3 倍速、音量、静音和循环。先设置 A，再跳到较后位置设置 B，可循环练习一段内容；时间点可以跳转或导出文本。

常见扩展名均会进入播放器，包括 MP3、WAV、FLAC、AAC、M4A、Opus、AIFF、WMA、MP4、WebM、MOV、MKV、AVI、WMV、FLV、MPEG、MTS、3GP、VOB 等。能否直接播放取决于 WebView2 的编码支持。点击「转换为兼容格式」使用随包 FFmpeg 转为 MP3，或 H.264 / AAC MP4。转换记录显示实时进度、错误与停止；最长 5 分钟，输出小于 500 MB。转换是临时播放副本，持久保存请点击「保存转换结果」，或把保存的文件重新拖入笔记。

损坏文件、DRM、特殊编码以及 MIDI 等需要合成器的格式无法保证转换。任意格式仍可作为原始附件保存和另存。转换器随包提供 GPL 许可及上游构建信息，路径为 `app/node_modules/ffmpeg-static/ffmpeg.exe.LICENSE` 和 `ffmpeg.exe.README`。

## 3D 查看器

支持 GLB / glTF、OBJ / MTL、STL、PLY、FBX、3MF。拖动旋转，滚轮缩放，右键平移；可重置视角、切换线框/网格、自动旋转、保存 PNG。可播放模型自带动画，并显示顶点、三角面和动画数量。

将包含模型、材质、二进制缓冲区和贴图的文件夹整体拖入，通过文件夹浏览器打开模型。把其中的模型单独放到画布时仍保留关联附件。单模型 100 MB，关联资源最多 200 个，总计 150 MB。联网资源、Draco / Meshopt / KTX 等需要附加解码器的资源暂不支持，缺失资源会显示具体名称。

## 数据分析

粘贴 CSV / TSV / JSON，或导入不超过 2 MB 的 CSV、TSV、JSON、XLSX。第一行是表头；JSON 支持对象数组或二维数组。Excel 读取第一个有数据的工作表，使用已缓存的单元格结果；需要其他工作表时分别导出 CSV。未计算的公式或超限数据会报错。XLSX 分析不会沿用 Office 预览的 1000 行截断。

「数据表」可直接编辑单元格与表头，添加行列、删行、点击箭头排序、按 50 行翻页。离开单元格后更新分析，筛选和排序不会改变编辑所指的原始行。顶部显示当前行数、有效数值、合计和平均。

「制作图表」依次选择分组列、数值列和求和 / 平均 / 计数，右侧实时显示图和聚合值。可切换柱状、折线、饼图，选择保持数据顺序、数值排序或名称排序；最多展示当前顺序的前 60 组。空值不当作测量到的 0；无效饼图会说明原因。点击「把图表放到画布」保存独立图表，点击「导出结果」保存筛选后的 CSV。

「列统计」查看有效数值、空值、不同值、总和、平均、中位数、范围和样本标准差。原始数据与分析配置随笔记保存；CSV 导出对公式文本作转义。需要编辑源码时展开底部“高级”。独立图表编辑器同样支持表格输入、增减行及系列、单位与 Excel / CSV 粘贴，无需 JSON。

## Next to do for agent

点击左侧「Agent Next to do」，进入独立于画布的项目模式。先在「连接 Agent」配置 MCP，并复制协作要求。新建独立项目后添加构想，或让 Agent 发布公开方案与任务。公开内容包括目标、依据、执行要求、验收标准、依赖、进展、产物和验证证据；方案、执行记录及代码资料分别可查看。

旧画布中的构想、方案、内部依赖连线和 Agent 记录会自动迁入关联项目，保留笔记编号。其他画布内容保留；完整备份和恢复同时包含两种模式的数据。

客户端需按以下协议执行：

1. `own_list_agent_projects` 查找项目，没有合适项目时使用 `own_create_agent_project` 创建。之后使用 `projectId` 调用协作工具。`own_publish_plan` 发布方案与可编辑任务，使用稳定 `requestId`，重试不会覆盖用户修改。
2. `own_agent_next` 领取依赖已完成的任务，获得笔记当前 `revision` 和 `leaseToken`。
3. 执行前、关键动作后和至少每 30 秒调用 `own_agent_report`，提交真实进展。凭证有效 120 秒，近期 75 秒内有心跳显示在线。
4. 用户修改要求、改变依赖、暂停或删除任务后，旧报告返回 `accepted: false, needsReplan: true`。停止旧方案，重新领取最新任务。恢复为待实现的前置任务也会使后续执行凭证失效。
5. 实际完成并验证后，提交 `status: done` 和 `evidence`。完成任务锁定要求；用户可以重新打开并保留原结果。

未收到近期心跳会显示离线；已过期的任务在下一次领取/报告时回到待实现。暂停任务不会被领取，循环依赖不会保存。恢复备份时会撤销旧凭证并清空在线记录。

Own 监控遵守此协议的客户端，不能读取未上报的内部 todo，也不会自动唤醒或启动外部 Agent。笔记修改在下一次检查时影响后续执行，已发生的外部动作需要 Agent 另行处理。用户修改不会扩大 Agent 原有授权范围。


## 1.4 长期工作与 MCP

Agent 项目顶部的“目标与约束”可编辑目标、工作范围、禁止事项和验收标准，并关闭代码/调试或媒体执行。“暂停整个项目”停止 Own 中绑定任务的运行；修改项目约束或公开方案也会使旧任务凭证失效。任务显示下一步和阻塞，“执行记录”可读完整交接笔记，恢复工作无需依赖单次聊天记忆。

MCP 提供一体化可编程应用工具：`own_configure_program_app` 选择 Flask 入口，`own_start_program_app` 启动，`own_program_app_request` 发送测试请求并读取响应，`own_program_app_status` 查看日志，`own_stop_program_app` 释放端口。`own_capabilities` 按功能提供调用步骤和示例。代码可显式运行、逐步调试、查看变量并保存真实输出；数据可分页分析、保留原始行号并生成带来源版本的图表；任意附件可分块上传、浏览目录、读回核验；媒体转换可保存永久结果，媒体/3D设置会应用到查看器，卡片关系可带标签与样式。详细参数见[MCP说明](mcp.md)。
